# Pop & Go – Test

Kostenloser, öffentlicher GitHub-Pages-Frontend-Prototyp. Verwendet ausschließlich den veröffentlichbaren Supabase-Clientschlüssel. **Keine Administrator- oder Service-Schlüssel hier speichern.**

## GitHub Pages

Repository: `5dbp6h96ch-droid/pop-and-go`

In den Repository-Einstellungen unter **Settings → Pages → Build and deployment** die Option **Deploy from a branch**, Branch **main**, Ordner **/(root)** auswählen und speichern. Danach ist die Testseite voraussichtlich unter `https://5dbp6h96ch-droid.github.io/pop-and-go/` erreichbar. Die URL erst nach tatsächlichem Test als funktionsfähig betrachten.

## Abnahme

- Safari zeigt eine gerenderte Oberfläche und keinen Quelltext.
- API lädt 43 Freizeitideen und 6 Kategorien.
- Suche und alphabetische Sortierung funktionieren.
- Acht bekannte Einträge haben Koordinaten.
- Favoriten bleiben lokal auf dem jeweiligen Gerät.
- Google-Apps-Script-Produktivbereitstellung und Rheinschiffer-Projekte bleiben unverändert.
